# İpucuları — yenidən baxış (təklif, 13 noyabr 2026)

Bütün 8 dərsin bütün tapşırıqları. Təsdiqdən sonra dərs fayllarına köçürüləcək.

## Qaydalar

1. **Cavabı demir.** Seçimin sözü, düzgün variant və ya axtarılan söz ipucunda yazılmır.
2. **Termin yoxdur.** “Şəkilçi”, “inkar”, “fel” kimi sözlər işlənmir.
3. **Yol göstərir:** vəziyyət barədə sual verir (görüş başlayır, yoxsa bitir? kim səhv etdi?) və ya harada öyrəndiyini xatırladır (“bu dərsin əvvəlində”, “Dərs 3-də”). Öyrənən kart nömrələrini görmür, ona görə “Kart 3” yazılmır.
4. **Qısadır:** 1–2 cümlə.
5. **Qrammatika boşluqlarında** Azərbaycanca paralel nümunə verilir, termin işlənmir.
6. **“Dinlə və təkrarla”** kartlarında ipucu yoxdur. Orada kömək “Yavaş dinlə” düyməsi və Azərbaycan hərfləri ilə oxunuşdur.
7. **Səsli və nümunəsiz tapşırıqlarda** iki pilləli kömək var: 1) bu cədvəldəki ipucu (nəticə Müstəqil qalır); 2) hazır nümunə (nəticə Köməklə olur).

## Dərs 1 — Salam və sağollaş

## Dərs 3 — Adını soruş

| Tapşırıq | Təklif |
|---|---|
| Oxu və anla | Qız sual verir, yoxsa özü haqqında nəsə deyir? Dərs 2-ni xatırla. |
| Mesajı qur | Bu dərsin əvvəlində öyrəndiyin ad sualını qur. Sual “Nə” mənasındakı sözlə başlayır. |
| Sözü tamamla | “Sənin adın” deyirik, “sən adın” yox. İngiliscə də “sən” və “sənin” fərqli sözlərdir. |
| Cavabı seç | Oğlan xoş söz dedi. Bu dərsdə ona qısa cavab öyrəndin: “Mən də”. |
| Dialoqu tamamla | Qız sənin adını soruşur. Dərs 2-də adını necə deyirdin? |

| Tanışlığa cavab (səsli) | Xoş sözə qısa cavab verilir: “Mən də”. |
| Söhbəti bitir | Görüş bitir. Dərs 1-in sağollaşma sözlərini xatırla. |
