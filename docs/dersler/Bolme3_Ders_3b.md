## Giriş — Giriş

Hosteldə qeydiyyat vərəqini doldurur, pasport nəzarətində millətini deyirsən.

- İngilis, amerikalı, alman və fransız sözlərini tanıya bilirəm.
- Formada millət sahəsini doldura bilirəm.
- Millətim soruşulanda cavab verə bilirəm.

## Kart 2 — Yeni söz

**English** — ingilis

Oxunuşu: inqliş · IPA: /ˈɪŋɡlɪʃ/

Quruluşu: England — ölkə; English — millət.

Nümunə: **I'm from England. I'm English.** — Mən İngiltərədənəm. İngilisəm.

Qeyd: Böyük hərflə yazılır: English.

## Kart 3 — Seç: Düz yazını seç

**Tapşırıq:** Hostelin qeydiyyat vərəqində ingilis qonağın milləti yazılıb. Hansı yazı düzdür?  
**Seçimlər:** English / english / England — **düzgün:** English  
**İpucu:** Həm hərfin böyüklüyünə, həm sözün sonuna bax.  
**Düzgün olanda:** Millət böyük hərflə yazılır: English.  
- *İzah (“english” seçiləndə):* Millət sözü böyük hərflə yazılır. — Uyğun: English. Səbəb: Azərbaycancada “ingilis” kiçik hərflə yazılır, ingiliscə isə böyük hərflə. Qayda: I'm English. — düzdür; I'm english. — olmur. Nümunə: I'm from England. I'm English.  
- *İzah (“England” seçiləndə):* England ölkədir, millət deyil. — Uyğun: English. Səbəb: Millət sahəsinə ölkə adı yox, millət yazılır. Qayda: I'm English. — millət; I'm from England. — ölkə. Nümunə: I'm from England. I'm English.  

**Təkrar (yeni vəziyyət):**

**Tapşırıq:** Qatarda bilet siyahısında rus sərnişinin milləti yazılıb. Hansı yazı düzdür?

## Kart 12 — Formanı doldur: Formanı doldur

**Tapşırıq:** Hostelə yazılırsan. Qeydiyyat vərəqini doldur (istəsən, uydurma məlumat).  
**Forma:** Hostel qeydiyyatı — Yeni qonaq  
**First name:** məna:  — nümunə: …  
**Last name:** məna:  — nümunə: Mammadova  
**Nationality:** məna:  — nümunə: Azerbaijani  
**İpucu:** Hər sətrin başlığını oxu; millət sətrinə ölkə adı yazılmır.  
**Düzgün olanda:** Adını, soyadını və millətini öz yerinə yazdın.  
- *İzah (“First name” səhv olanda):* Uyğun: … Səbəb: Bu sətirdə yalnız adın lazımdır. Qayda: First name — adın; Last name — soyadın. Nümunə: My first name is …  
- *İzah (“Last name” səhv olanda):* Uyğun: Mammadova. Səbəb: Bu sətirdə yalnız soyadın lazımdır. Qayda: Last name — soyadın; First name — adın. Nümunə: My last name is Mammadova.  
- *İzah (“Nationality” səhv olanda):* Uyğun: Azerbaijani. Səbəb: Nationality sətrinə ölkə yox, millət yazılır. Qayda: Nationality: Azerbaijani. ; Where are you from? — Azerbaijan. Nümunə: Nationality: Azerbaijani.  

**Təkrar (yeni vəziyyət):**

**Tapşırıq:** Amerikalı dostunu hostelə yazırsan. Pasportunda latın hərfləri ilə belə yazılıb: “SMITH ANNA”, ölkə — the USA. Formanı doldur.  
**Forma:** Hostel qeydiyyatı — Yeni qonaq  
**Last name:** dəqiq: Smith  
**First name:** dəqiq: Anna  
**Nationality:** dəqiq: American  
**İpucu:** Hər sətrin başlığını oxu; millət sətrinə ölkə adı yazılmır.  
**Düzgün olanda:** Soyadı, adı və milləti öz yerinə yazdın.  
- *İzah (“Last name” səhv olanda):* Uyğun: Smith. Səbəb: Last name — soyaddır: pasportdakı birinci söz. Qayda: Last name — Smith; First name — Anna. Nümunə: My last name is Smith.
