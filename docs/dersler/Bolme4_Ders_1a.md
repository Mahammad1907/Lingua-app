# Dərs 1 · 1-ci hissə — Bu kimdir?

Bölmə 4 · Ailə və insanlar. Bu sənəd `src/data/unit4/lesson1a.ts`-dən yaradılıb — mətni orada dəyiş, sonra `node scripts/export-unit1-docs.cjs`.

## Giriş — Giriş

Dostun sənə evinin qapısını açır və ailə albomunu göstərir. Bir tanışını təqdim edir, kim olduğunu soruşursan.

- Başqasını təqdim edə bilirəm.
- Şəkildəki adamın kim olduğunu soruşa bilirəm.
- Qonağı qarşılaya bilirəm.

## Kart 2 — Yeni söz

**This is [ad].** — Bu [ad]-dır.

Oxunuşu: **th**is iz [ad]. · IPA: /ðɪs ɪz/

Quruluşu: This is + ad.

Nümunə: **Hello! This is Tom.** — Salam! Bu Tomdur.

Qeyd: This — bu; is — “-dır”. İkisi ayrı deyilir.

## Kart 3 — Müəllim izahı

Başqasını This is ilə təqdim edirsən.

**1 · Kimi təqdim edirsən?**
- I'm [ad]. · özümü
- This is [ad]. · başqasını

**2 · Necə qurulur?**
- This is + ad
- **This is Tom.** — Bu Tomdur.

Diqqət et: Azərbaycancada “-dır” sonda gəlir. İngiliscə is adın əvvəlində ayrıca söz kimi gəlir.

## Kart 4 — Seç: Dinlə və anla

**Tapşırıq:** Dostunun qapısındasan. O, yanındakı adamı sənə göstərir. O nə edir?  
**Səs:** Hi! This is Anna.  
**Seçimlər:** Yanındakı adamı təqdim edir. / Özünü təqdim edir. / Adını soruşur. — **düzgün:** Yanındakı adamı təqdim edir.  
**İpucu:** İlk iki sözə qulaq as: danışan özündən, yoxsa başqasından danışır?  
**Düzgün olanda:** This is + ad başqasını təqdim edir.  
- *İzah (“Özünü təqdim edir.” seçiləndə):* Özünü I’m ilə təqdim edirlər. — Uyğun: Yanındakı adamı təqdim edir. Səbəb: Özünü I’m ilə təqdim edirsən; səsdə This is var — başqasını təqdim edir. Qayda: I'm Anna. — özüm; This is Anna. — başqası. Nümunə: Hi! This is Anna.  
- *İzah (“Adını soruşur.” seçiləndə):* Səsdə ad soruşan sual yoxdur. — Uyğun: Yanındakı adamı təqdim edir. Səbəb: Ad soruşanda “What’s your name?” deyilir; burada This is var. Qayda: What's your name? — ad soruşur; This is Anna. — təqdim edir. Nümunə: Hi! This is Anna.  

**Təkrar (yeni vəziyyət):**

**Tapşırıq:** Kafedə dostun yanındakı qadını sənə göstərir. O nə edir?  
**Səs:** Hello! This is Emma.  
**Seçimlər:** Adını soruşur. / Özünü təqdim edir. / Yanındakı qadını təqdim edir. — **düzgün:** Yanındakı qadını təqdim edir.  
**İpucu:** Hello-dan sonrakı iki sözə qulaq as: danışan kimdən danışır?  
**Düzgün olanda:** This is + ad başqasını təqdim edir.  
- *İzah (“Özünü təqdim edir.” seçiləndə):* Özünü I’m ilə təqdim edirlər. — Uyğun: Yanındakı qadını təqdim edir. Səbəb: Özünü I’m ilə təqdim edirsən; səsdə This is var — başqasını təqdim edir. Qayda: I'm Emma. — özüm; This is Emma. — başqası. Nümunə: Hello! This is Emma.

## Kart 5 — Yeni söz

**friend** — dost

Oxunuşu: frend · IPA: /frɛnd/

Nümunə: **Hi, friend!** — Salam, dostum!

Qeyd: Yazılışa diqqət: friend — i-dən sonra e gəlir.

## Kart 6 — Yaz: Dinlə və yaz

**Tapşırıq:** Eşitdiyin sözü yaz.  
**Səs:** friend  
**Qəbul:** dəqiq: friend  
**İpucu:** Sözün ortasında iki saitin ardıcıllığına diqqət et.  
**Düzgün olanda:** friend — i-dən sonra e gəlir.  
- *İzah (başqa səhvdə):* Yazılış: f-r-i-e-n-d. — Uyğun: friend. Səbəb: Sözün ortasında əvvəl i, sonra e gəlir. Qayda: friend — düzdür; freind — olmur. Nümunə: Hi, friend!  
- *İzah (başqa səhvdə):* Eşitdiyin söz: friend. — Uyğun: friend. Səbəb: Eşitdiyin sözü hərf-hərf yaz: f-r-i-e-n-d. Qayda: friend — dost. Nümunə: Hi, friend!

## Kart 7 — Yeni söz

**my friend** — mənim dostum

Oxunuşu: may frend · IPA: /maɪ frɛnd/

Quruluşu: my + friend

Nümunə: **This is my friend.** — Bu mənim dostumdur.

Qeyd: my — mənim, friend — dost: “dostum” ingiliscə iki sözdür.

## Kart 8 — Sözü tamamla: Sözü tamamla

**Tapşırıq:** Parkda dostun yanındakı qızı sənə təqdim edir. Hansı söz çatmır?  
**Cümlə:** Hi! This ___ my friend.  
**Seçimlər:** is / are / am — **düzgün:** is  
**İpucu:** Bir nəfəri təqdim edir — “-dır” üçün hansı söz lazımdır?  
**Düzgün olanda:** This ilə is gəlir: This is my friend.  
- *İzah (“are” seçiləndə):* This ilə are olmur: is gəlir. — Uyğun: is. Səbəb: Bir nəfəri təqdim edəndə This is deyilir. Qayda: This is my friend. — düzdür; This are my friend. — olmur. Nümunə: This is my friend.  
- *İzah (“am” seçiləndə):* am yalnız I ilə gəlir: I am. — Uyğun: is. Səbəb: am “mən” ilə gəlir; This ilə is gəlir. Qayda: I'm Tom. — mən; This is Tom. — başqası. Nümunə: This is my friend.  

**Təkrar (yeni vəziyyət):**

**Tapşırıq:** Kafedə oğlan yanındakı oğlanı sənə təqdim edir. Hansı söz çatmır?  
**Cümlə:** Hello! This ___ Tom.  
**Seçimlər:** am / is / are — **düzgün:** is  
**İpucu:** Yanındakı adamı təqdim edir — This-dən sonra hansı söz gəlir?  
**Düzgün olanda:** This ilə is gəlir: This is + ad.  
- *İzah (“are” seçiləndə):* This ilə are olmur: is gəlir. — Uyğun: is. Səbəb: Bir nəfəri təqdim edəndə This is deyilir. Qayda: This is Tom. — düzdür; This are Tom. — olmur. Nümunə: Hello! This is Tom.  
- *İzah (“am” seçiləndə):* am yalnız I ilə gəlir: I am. — Uyğun: is. Səbəb: am “mən” ilə gəlir; This ilə is gəlir. Qayda: I'm Tom. — mən; This is Tom. — başqası. Nümunə: Hello! This is Tom.
